# 星蛇 · Star Snake

**3.0.0 试玩版**。收集星核，让身体变长；按住 Q 时停，选择方向，松开后消耗尾巴施放技能。远征采用固定 60°斜俯视正交画面，原来的糖果经典与三关保留在“附加模式”。

## 运行

需要 Node.js 24.15 以上的 24.x，或 26 及以上。当前开发和 CI 固定使用 24.19.0。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。发布时执行：

```sh
npm run check
npm run build
npm run preview -- --port 4173
```

`dist/index.html` 内嵌脚本、样式和字体，可复制或双击打开。浏览器自动化使用 HTTP 预览；双击验收步骤见 [VALIDATION.md](VALIDATION.md)。

## 操作与规则

- 方向键 / WASD 移动，P / Esc 暂停，空格开始或重试。
- **按住 Q**：立即时停，方向键选择方向；松开或到 1.2 秒时施法。直接反向无效。
- 释放后沿选定方向继续移动，先停顿 60ms，再走完整一步。默认一步 150ms，缓时为 225ms。
- 触屏可滑动或使用方向按钮；按住技能按钮拖动选方向，松手施法。手柄使用方向键 / 左摇杆，X 或 RB 施法。
- 暂停、失焦、触控取消和手柄断开会取消瞄准并暂停，不消耗身体。超时施法后必须松键才能再次触发。
- 开局 6 节，最多 12 节；Q 默认消耗 3 节，至少保留 3 节。9 节达到二级，12 节达到三级。
- 破岩：击碎所选方向 1 / 2 / 3 格内的裂岩。缓时：持续 8 / 12 / 16 步。牵引：吸取所选方向 2 / 3 / 4 格内第一颗星核。
- 三颗心，六个区域，十张手工地图，九项升级。收齐目标后进入星门；撞击从本区入口重试，升级保留。

目标角标、施法范围与危险提示始终保留。设置可选择精简特效、关闭震动或静音。

## 存档兼容

包名、所有玩法 ID 和原存档键保持兼容：经典最高分、糖果三关、远征检查点分别保存。旧远征在新主题下恢复同一房间入口。星星 / 月牙 / 晶体 / 星环只是原水果 ID 的显示映射。

画面设置使用独立键 `starSnakeVisualSettings`，不写入远征数据。浏览器存储失效时当前会话仍可游玩；桌面版通过隔离的 preload 访问白名单文件存档。

## 开发与审查

| 命令                      | 用途                               |
| ------------------------- | ---------------------------------- |
| `npm run typecheck`       | TypeScript strict                  |
| `npm run lint`            | ESLint、类型穷尽与核心依赖边界检查 |
| `npm run format:check`    | 检查格式                           |
| `npm test`                | 核心、输入、存档和生命周期回归     |
| `npm run check`           | 以上全部检查                       |
| `npm run build`           | 单 HTML 构建与资源内嵌检查         |
| `npm run desktop:package` | 打包 Windows x64                   |
| `npm run desktop:verify`  | 核对桌面文件与 ASAR 内容           |
| `npm run desktop:smoke`   | 真实启动、沙箱和文件存档检查       |
